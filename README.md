# 🎮 Салонная Смена — Android игра

> **Roger Production** представляет полноценный симулятор продавца с псевдо-3D графикой, физикой движения и продуманными сценариями.

## 📱 О игре

**Салонная Смена** — многоуровневый симулятор работы продавца/кассира с 5 главами, 20 уровнями и 4 уникальными персонажами. Обслуживай клиентов, выполняй план, набирай комбо и получай ранги от C до S!

## 🎯 Игровой процесс

```
Roger Production → Главное меню → Выбор персонажа → Выбор локации → Игра → Результат
```

- Псевдо-3D сцена с перспективой и тенями
- Физика движения: ускорение, торможение, коллизии
- Очередь клиентов двигается к кассе, терпение падает
- Комбо-множитель за серии без ошибок
- Ранги C / B / A / S по результату уровня
- Профильный бонус +20% за свою локацию

## 🔧 Сборка APK

### Требования
- JDK 17+
- Android SDK (API 21+)

### Команда
```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

### GitHub Actions
При каждом push в `main` автоматически запускается сборка debug APK.

**Где скачать artifact:**
1. Перейди во вкладку **Actions**
2. Открой последний workflow **"Build Debug APK"**
3. Скачай **SalonSmena-debug** из раздела Artifacts
4. Установи на Android (разреши установку из неизвестных источников)
